# Cardulator 🧮

**Cardulator** — это продвинутая инженерно-математическая прошивка для портативного компьютера **M5Stack Cardputer** (ESP32-S3), превращающая устройство в полнофункциональный программируемый калькулятор с поддержкой REPL, СИ-приставок, функций, массивов, собственного скриптового языка, построения 2D-графиков и NVS/SD накопителя.

---

## 🌟 Основные возможности

- **Вычисление выражений в режиме REPL**: Двойная точность (`double`), поддержка научной нотации (`1e5`), СИ-приставок (`1.5k`, `2M2`, `10u`), истории вычислений (`e1`, `e2`...).
- **Продвинутый скриптовый движок (`Fn + S`)**: Поддержка блоков кода, ветвлений (`if` / `else`), циклов (`while`, `for`), массивов, вывода `print()` и функции `sleep()`.
- **Построение 2D-графиков (`Fn + G`)**: Построение функций и наборов точек, панорамирование, масштаб, турбо-навигация, сохранение нескольких графиков (`hold`).
- **Мастер Формул (`Fn + F`)**: Быстрое создание и интерактивный вызов шаблонов формул с несколькими параметрами.
- **Менеджеры Переменных (`Fn + V`), Констант (`Fn + C`), Биндов (`Fn + B`) и Параметров (`Fn + P`)**.
- **Двойная буферизация экрана**: 100% плавный интерфейс без мерцания и задержек.
- **Интеграция с M5Burner & GitHub Releases**: Автоматическая сборка объединенного бинарника (`esptool merge-bin`) и публикации в релизы.

## ⌨️ Навигация и горячие клавиши

| Сочетание | Описание |
| :--- | :--- |
| **`Fn + V`** | Открыть менеджер переменных |
| **`Fn + S`** | Открыть менеджер скриптов |
| **`Fn + G`** | Открыть режим 2D-графиков |
| **`Fn + B`** | Открыть менеджер биндов |
| **`Fn + F`** | Открыть мастер формул |
| **`Fn + C`** | Открыть менеджер констант |
| **`Fn + P`** | Открыть настройки параметров |
| **`Fn + H`** | Показать контекстную справку |
| **`Esc` / `` ` `` / `[`** | Назад / Отмена |
| **`N`** | Создать новый элемент (в списках) |
| **`R`** | Переименовать имя (в списках переменных/констант) |
| **`E` / `Enter`** | Изменить значение (в списках переменных/констант) |
| **`Del` / `Backspace`** | Удалить выбранный элемент |

## 🧪 Автоматическое модульное тестирование

Запуск всех тестов на хост-системе (без прошивки контроллера):

```bash
./build_all.sh -t
```

## 🛠️ Сборка и прошивка

```bash

./build_all.sh

pio run -e cardputer -t upload
```

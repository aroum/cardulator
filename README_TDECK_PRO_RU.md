# Cardulator для LilyGO T-Deck Pro

[English Guide](README_TDECK_PRO.md) | [Главный README](README_RU.md)

В этом документе описывается работа и особенности порта **Cardulator** для устройства **LilyGO T-Deck Pro** (ESP32-S3 с 3.1" экраном E-Paper и физической 35-клавишной матричной клавиатурой).

---

## 📱 Аппаратная поддержка и ревизии платы

LilyGO выпустила 3 аппаратные ревизии серии **T-Deck Pro**. Cardulator поддерживает работу на экране E-Ink и клавиатуре TCA8418 во всех ревизиях:

| Версия платы | Тактильный отклик (DRV2605 @ 0x5A) | Расширитель портов (XL9555 @ 0x20) | Драйвер клавиатуры | Дисплей | Статус |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **T-Deck Pro V1.0** | ❌ | ❌ | TCA8418 (I2C `0x34`) | GDEQ031T10 (320×240 E-Ink) | **Поддерживается** |
| **T-Deck Pro V1.1** | ✅ | ❌ | TCA8418 (I2C `0x34`) | GDEQ031T10 (320×240 E-Ink) | **Поддерживается** |
| **T-Deck Pro MAX** | ✅ | ✅ | TCA8418 (I2C `0x34`) | GDEQ031T10 (320×240 E-Ink) | **Поддерживается** |

### Дисплей и особенности отображения
- **Панель**: 3.1-дюймовый монохромный дисплей E-Paper (320 × 240 пикселей).
- **Цветовая схема**: Инвертированная высококонтрастная тема, оптимизированная для электронной бумаги: четкие черные символы на чистом белом фоне.
- **Быстрое частичное обновление (Partial Refresh)**: Дифференциальный буфер обновляет только измененные строки экрана, обеспечивая минимальные задержки при наборе текста и вычислениях.
- **Полная очистка экрана (Full Refresh)**: Принудительный полный цикл перерисовки E-Ink для устранения артефактов ("ghosting") вызывается в любой момент комбинацией **`Alt + r`**.

## ⌨️ Раскладка клавиатуры и управление

T-Deck Pro оснащен 4-рядной физической клавиатурой, управляемой микросхемой **TCA8418** по шине I2C. Cardulator реализует многослойную систему ввода с помощью модификаторов **`Sym`**, **`Shift`** и **`Alt`**.

### Поведение модификаторов
- **`Alt` (Ряд 2, Колонка 0)**: Работает аналогично клавише **`Fn`** на M5Stack Cardputer. Используется для переключения экранов меню, навигации по истории и строкам, а также для горячих клавиш редактирования.
- **`Sym` (Ряд 3, Колонка 8)**: Включает / фиксирует **слой цифр и математических символов** (`0–9`, знаки операций, пунктуация).
- **`Shift` (Левый `r3c5`, Правый `r3c9`)**: Переключает заглавные буквы и дополнительные специальные символы.
- **Навигация WASD**: Во всех экранах без текстовых полей (переменные, константы, параметры, скрипты, формулы) клавиши **`w`**, **`a`**, **`s`**, **`d`** работают как стрелочки Вверх/Влево/Вниз/Вправо как с `Alt`, так и без него.

## 🎯 Быстрая справка: Скобки и спецсимволы

| Символ | Как ввести |
|:---:|:---|
| **`(`** и **`)`** | `Sym + t` и `Sym + y` |
| **`[`** и **`]`** | `Alt + t` и `Alt + y` |
| **`{`** и **`}`** | `Shift + Sym + t` и `Shift + Sym + y` |
| **`<`** и **`>`** | `Shift + Sym + n` и `Shift + Sym + m` |
| **`=`** | Нажать клавишу **`=`** (`$`), либо `Shift + Sym + o`, либо `Alt + e` |
| **`\`** | `Shift + Sym + g` |
| **`&`** | `Shift + Sym + u` |
| **`\|`** | `Sym + p` или `Shift + Sym + p` |
| **`^`** | `Shift + Sym + f` |
| **`%`** | `Shift + Sym + d` |
| **`Tab`** | Нажать клавишу **`0`** без слоя Sym, либо **`Alt + Пробел`** |
| **Удаление слова** | **`Alt + Backspace`** |
| **Возврат в REPL** | **`Alt + q`** |

## 🛠️ Сборка и прошивка через PlatformIO

### 1. Сборка прошивки
В `platformio.ini` настроено отдельное окружение `tdeck-pro`:

```bash
# Компиляция прошивки для T-Deck Pro
pio run -e tdeck-pro

# Или через скрипт сборщика
./build_all.sh -p tdeck-pro
```

### 2. Загрузка в устройство
Подключите T-Deck Pro по кабелю USB-C (убедитесь, что переключатель питания включен):

```bash
pio run -e tdeck-pro -t upload
```

### 3. Мониторинг последовательного порта
Cardulator выводит отладочные сообщения USB CDC и поддерживает удаленный ввод на скорости 115200 бод:

```bash
pio device monitor -b 115200
```
